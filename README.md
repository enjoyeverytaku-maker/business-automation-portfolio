# Business Automation Portfolio

経理・財務・不動産売買の実務理解を土台に、  
**Google Apps Script / スプレッドシート / Python / AI活用** で  
業務を「現場で使える形」に整えるためのポートフォリオです。

単にコードを書くのではなく、  
**ヒアリング → 要件整理 → 小さく試作 → 実務に合わせて改善** の流れで、  
運用しやすい仕組みづくりを重視しています。

---

## できること

- Google Apps Script を使った業務自動化
- Googleスプレッドシートの集計・整形・転記自動化
- CSV / Excel データの整形・前処理
- 経理業務の補助ツール作成
- 入金管理・請求管理・帳票作成の効率化
- 業務フローの整理と、運用しやすい形への落とし込み
- AIを使った文書作成・情報整理・補助業務の効率化

---

## 強み

### 1. 実務理解がある
経理・財務、不動産売買の業務に関心と実務理解があるため、  
単なるツール作成ではなく、**現場の流れに沿った改善案**を考えやすいです。

### 2. 小さく作って、確認しながら広げる
最初から大きく作り込まず、  
まずは **MVP（最小構成の試作版）** を作って認識差を減らし、  
そこから段階的に広げる進め方を重視しています。

### 3. 「使える形」で納品する
コードだけで終わらせず、必要に応じて以下も整理します。

- README
- 導入手順
- 設定ファイル例
- テスト観点
- カスタマイズしやすい構成

## サンプルプロジェクト

### 1. GAS Invoice Helper
Google Apps Script を使った、請求・入金管理補助のサンプルです。  
請求関連の業務を、手作業前提から少しずつ整えていくことを想定しています。

想定用途
- 請求情報の整理
- 入金確認補助
- 管理表の更新補助

---

### 2. Spreadsheet Reconciliation
スプレッドシートを使った集計・照合補助のサンプルです。  
複数データの突合や、定型集計の効率化を想定しています。

想定用途
- 入出金一覧の整理
- 照合作業の補助
- 月次集計の簡略化

---

### 3. Python CSV Cleaner
CSVデータを整形・前処理する Python サンプルです。  
列名ゆれ、不要行、形式差異があるデータの一次整形を想定しています。

想定用途
- CSV取込前の整形
- データ前処理
- 手作業コピペの削減
