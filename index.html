Process

進め方

受注から納品まで、全案件共通のステップです。仕様確定前に認識齟齬をなくすことを重視しています。

ヒアリング

ヒアリングシートを送付し、現状フロー・課題・ゴールを確認します。サンプルデータがあれば共有をお願いします。

目安：1営業日以内に回答

仕様確定

仕様書を作成してお送りし、着手前に認識齟齬を解消します。OKをいただいてから開発を開始します。

目安：ヒアリング後1営業日

開発・テスト

仕様書通りに実装し、テスト用サンプルデータで正常系・異常系・境界値を確認します。

目安：2〜10営業日（複雑度による）

納品

ソースコード + README + セットアップ手順書 + 操作マニュアルを同梱してお渡しします。

目安：開発完了後当日〜翌日

アフターサポート

納品後3日以内のバグ修正は無償です。追加機能・仕様変更は別途お見積りします。

FAQ

よくある質問

どんな案件に対応できますか？

Google Apps Script（GAS）を使ったスプレッドシート自動化、Python を使った CSV/データ整形、Excel VBA の保守・改修、Claude API を使った業務自動化が主な対応領域です。

常駐・出社は可能ですか？

リモートワーク専門のため、常駐・出社が必要な案件はお受けできません。

見積もりはどのように出しますか？

ヒアリング後に要件を整理し、工数×単価でお見積りします。概算が必要な場合は案件内容をお聞きした上でお伝えします。

小さい案件（数千円規模）も対応できますか？

最低受注金額は設けていませんが、ヒアリング・仕様確定のコストを考慮し、¥10,000以上を推奨しています。

開発期間の目安は？

小規模（1〜2機能）で2〜5営業日、中規模（複数機能連携）で5〜10営業日が目安です。急ぎの場合はご相談ください。

ソースコードは納品してもらえますか？

はい、全コードを納品します。著作権はクライアント様に帰属します。

納品後にバグが見つかった場合は？

納品後3日以内の不具合修正は無償です。期間後は別途お見積りします。

引き継ぎ資料はありますか？

セットアップ手順・操作マニュアル・トラブルシューティングを必ず同梱します。IT知識がない担当者でも運用できる粒度を心がけています。
