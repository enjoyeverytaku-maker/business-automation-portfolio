1｜中堅企業・管理部門

Slack ワークフローの重複処理・通知漏れを根本から解決

課題　案件登録が集中すると同じ案件が重複処理され、通知漏れ・二重通知も起きていた。実データでは数千件中100件超の重複。

対応　ログを分析して取りこぼしの構造的な原因を特定。「通知を待つ」方式から「状態を定期的に見に行く」方式に変え、kintone の重複禁止設定で二重登録を防止。切り戻し手順書も作成。

応急処置を即日で本番反映 → kintone 連携版を納品し、継続のご依頼につながりました

Google Apps Script / Slack Workflow Builder / kintone REST API

2｜中堅企業・情報システム

GAS の変更を「セーブ」して戻せる社内向け変更管理システム

課題　業務で GAS を多数使っているが、変更前との差分確認や元に戻す手段がなく、修正ミスが怖くて手を入れられない状態。

対応　ブラウザだけでソースの取得・差分表示・セーブ・ワンクリック復元・変更の承認ができる仕組みを、お客様自身の Google Cloud 上に構築。操作マニュアル・管理者ガイド・検収チェックリストを作成。

納品・検収完了。エンジニアでない担当者が GAS の変更を管理できるようになりました

Apps Script API / Google Cloud Run / Google OAuth ／ 本体コード（GitHub）

3｜中堅企業・経理部

メールで届く請求書 PDF をフォルダへ自動保存

課題　取引先から共有アドレスに届く請求書を、担当者が毎回ダウンロードして保存していた。

対応　添付 PDF を送付先ごとに決めた Google ドライブのフォルダへ自動保存する GAS を作成。設定値はコードを触らず画面から登録できる形にし、社内の担当者が自分で設置できる手順書を用意。

経理部で稼働中です

Google Apps Script / Gmail / Google ドライブ

4｜中堅企業・全社

部署ごとの申請・承認ワークフローの基盤構築

課題　部署ごとにバラバラだった申請・承認を、共通の仕組みで回したい。申請内容は後から案件単位で追えるようにしたい。

対応　申請の入口となる親ワークフローと中央の管理表を構築し、案件番号で kintone と紐づける設計に。法務部門の申請12種類は、差し戻しの可否・回数・再入力の範囲を事前に質問して確定させてから設計しました。

基盤を納品。各部署への展開はお客様側の方針に合わせて進めています

Slack Workflow Builder / Google スプレッドシート / Google Apps Script / kintone

5｜中堅企業・営業部門

基幹システム刷新に向けた現行業務の調査

課題　外部ベンダーによる基幹システムの作り直しが始まるが、現場で Slack や kintone を使って実際にどう業務が回っているか、まとまった資料がなかった。

対応　業務工程の一覧と元資料との差分、ヒアリングで確認すべき点のリスト、帳票とシステムの対応表を作成し、kintone の全スペースを棚卸し。

ベンダーとの要件すり合わせ用の資料として納品しました

kintone / Slack / 業務フロー整理

6｜福祉・介護サービス法人

複数口座の出納帳から資金繰り表を自動作成

課題　金融機関・支援機関に出す資金繰り表を、複数口座の出納帳から毎月手作業で作っていた。

対応　科目の対応表で自動仕分けし、日繰り資金繰り表と月次推移表を自動作成。予定と実績を色分けして二重計上を防ぎ、通帳残高との差異も自動チェック。

納品後も科目の追加・並び替え機能などの追加要望に対応しています

Google Apps Script / Google スプレッドシート

7｜卸売・EC 事業者

会計クラウドの初期設定と EC モール・銀行連携

課題　会計ソフト未導入で、複数の EC モールの売上・手数料や銀行明細の管理が煩雑だった。

対応　チャネル別に損益が見える勘定科目・補助科目を設計し、銀行・カード・EC モールを連携して自動仕訳ルールを作成。旧データと二重計上にならない移行方法も設計。

納品完了。お客様側での運用に移行しました

Process

進め方

受注から納品まで、全案件共通のステップです。仕様確定前に認識齟齬をなくすことを重視しています。

ヒアリング

ヒアリングシートを送付し、現状フロー・課題・ゴールを確認します。サンプルデータがあれば共有をお願いします。

目安：1営業日以内に回答

仕様確定

仕様書を作成してお送りし、着手前に認識齟齬を解消します。OKをいただいてから開発を開始します。

目安：ヒアリング後1営業日

開発・テスト

仕様書通りに実装し、テスト用サンプルデータで正常系・異常系・境界値を確認します。

目安：2〜10営業日（複雑度による）

納品

ソースコード + README + セットアップ手順書 + 操作マニュアルを同梱してお渡しします。

目安：開発完了後当日〜翌日

アフターサポート

納品後3日以内のバグ修正は無償です。追加機能・仕様変更は別途お見積りします。

FAQ

よくある質問

どんな案件に対応できますか？

スプレッドシート・Google Apps Script の自動化、kintone・Slack ワークフローの構築と改修、会計クラウドの初期設定・連携、Excel VBA の改修が中心です。「こんなときにご相談ください」の一覧に近いものがあればお気軽にどうぞ。

常駐・出社は可能ですか？

リモートワーク専門のため、常駐・出社が必要な案件はお受けできません。

見積もりはどのように出しますか？

ヒアリング後に要件を整理し、工数×単価でお見積りします。概算が必要な場合は案件内容をお聞きした上でお伝えします。

小さい案件（数千円規模）も対応できますか？

最低受注金額は設けていませんが、ヒアリング・仕様確定のコストを考慮し、¥10,000以上を推奨しています。

開発期間の目安は？

小規模（1〜2機能）で2〜5営業日、中規模（複数機能連携）で5〜10営業日が目安です。急ぎの場合はご相談ください。

ソースコードは納品してもらえますか？

はい、全コードを納品します。著作権はクライアント様に帰属します。

納品後にバグが見つかった場合は？

納品後3日以内の不具合修正は無償です。期間後は別途お見積りします。

引き継ぎ資料はありますか？

セットアップ手順・操作マニュアル・トラブルシューティングを必ず同梱します。IT知識がない担当者でも運用できる粒度を心がけています。

対応できないことはありますか？

常駐・出社が必要な業務、フルタイム拘束（週30時間以上）の案件はお受けできません。またインボイス（適格請求書）の発行には対応しておりません（未登録のため）。
