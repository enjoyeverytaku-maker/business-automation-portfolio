# 作業フロー（受注〜納品）

## 全体像

```
受注連絡
  │
  ▼
① ヒアリング
   ・ヒアリングシートを送付
   ・現状フロー・課題・ゴールを確認
   ・サンプルデータがあれば共有をお願いする
  （目安: 1営業日以内に回答）
  │
  ▼
② 仕様確定
   ・spec.md（仕様書）を作成してクライアントに送付
   ・認識齟齬をこの時点で解消
   ・着手 OK をもらってから開発開始
  （目安: ヒアリング後1営業日）
  │
  ▼
③ 開発・テスト
   ・仕様書通りに実装
   ・テスト用サンプルデータで動作確認
   ・正常系・異常系・境界値のチェック
  （目安: 仕様複雑度に依存、2〜10営業日）
  │
  ▼
④ 納品
   ・ソースコード + README + セットアップ手順書 + 操作マニュアル
   ・受入確認チェックリストを同梱
   ・クライアントに動作確認をお願いする
  （目安: 開発完了後当日〜翌日）
  │
  ▼
⑤ アフターサポート
   ・納品後3日以内のバグ修正は無償
   ・追加機能・仕様変更は別途お見積り
```

---

## コミュニケーション方針

| 項目 | 方針 |
|------|------|
| 返信速度 | 営業時間内（9〜18時）に原則当日返信 |
| 報告頻度 | 開発中は1〜2日に1回進捗報告 |
| 不明点 | 推測で進めず、確認してから着手 |
| 変更管理 | 仕様変更は changelog.md に記録 |

---

## 納品物の標準セット

```
README.md            概要・セットアップ手順
setup_guide.md       詳細手順（スクリーンショット付き）
operation_manual.md  日常運用マニュアル
troubleshooting.md   よくあるエラーと対処法
src/                 ソースコード
tests/               テストコード（Python の場合）
sample_data/         サンプルデータ
changelog.md         変更履歴
```
