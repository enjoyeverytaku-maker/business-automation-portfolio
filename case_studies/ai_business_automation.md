# 事例：Claude API × GAS で業務テキストの自動仕分け・要約

## 概要

バックオフィス業務で毎日届く問い合わせメール・申請フォームの回答を
Claude API + GAS で自動分類・要約し、担当者の振り分け作業を自動化した事例。

## 課題

- 日次で50〜80件届く問い合わせメールを担当者がカテゴリ分けしてチームへ転送する作業が毎朝1〜2時間かかっていた
- フォーム回答の内容を要約して Slack に投稿する作業も手動で行っていた
- 内容によって対応優先度が変わるが、判断基準が属人化していた

## 解決アプローチ

1. 分類ルールをヒアリングで整理し「カテゴリ × 優先度」の判定基準を文書化
2. Claude API にカテゴリ定義と判定基準をシステムプロンプトとして渡し、JSONで返答させる設計
3. MVP として「メール分類 → スプレッドシートへの記録」だけを先に実装し、効果確認後に Slack 通知を追加

## 実装内容

- Gmail API でラベル付きメールを取得 → Claude API で分類・優先度判定・要約を JSON で取得
- 分類結果をスプレッドシートに記録（カテゴリ / 優先度 / 要約 / 件名 / 受信日時）
- 優先度「高」の案件は即時 Slack 通知
- フォーム回答（Google フォーム）も同様に Claude で要約 → スプレッドシート + Slack
- 毎朝8時に前日分を一括処理するトリガーを設定

## 使用技術

- Google Apps Script
- Claude API（Anthropic API / claude-haiku-4-5 で低コスト運用）
- Gmail API
- Google スプレッドシート
- Slack Webhook

## 工夫したポイント

- プロンプトにカテゴリ定義・判定例を明示し、出力を必ず JSON 形式に固定（パース失敗対策）
- API コスト削減のため、メール本文は最初の500文字のみ送信（Subject + 冒頭で十分な精度）
- 誤分類があった場合に担当者がシート上で修正 → 修正ログを蓄積して定期的にプロンプトを改善

## 効果

- メール振り分け作業：毎朝1〜2時間 → 確認・補正のみ15〜20分
- 優先度の高い案件への初動対応が平均30分以上早くなった
- 分類基準がシステムプロンプトとして文書化され、属人化が解消

## 向いているクライアント

- 毎日大量のメール・フォーム回答が届いており、仕分け作業が負担になっている
- 対応優先度の基準はあるが、担当者によってブレがある
- Claude / ChatGPT を使ってみたいが、業務への組み込み方がわからない
