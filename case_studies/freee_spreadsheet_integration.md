# 事例：freee × スプレッドシート 連携自動化

## 概要

中小企業の経理担当者が freee と Google スプレッドシートの間で毎月行っていた
手動のデータ転記・集計作業を GAS + freee API で自動化した事例。

## 課題

- freee の取引データを毎月末に CSV エクスポート → スプレッドシートへ貼り付け → 集計という手順が月3〜4時間かかっていた
- 勘定科目ごとの予実比較を手動で作成しており、月次締め後2〜3日かかっていた
- 経費精算の承認済み件数・金額を freee から確認するのに都度ログインが必要だった

## 解決アプローチ

1. freee API の認証フロー（OAuth2）をスプレッドシート上のボタンで完結できるよう実装
2. 毎月1日の早朝に前月データを自動取得・集計するトリガーを設定
3. 予実比較はマスターシートの予算列と自動取得データを突合するテンプレートを設計

## 実装内容

- freee API を使って取引データ（収入・支出・勘定科目）を自動取得
- 勘定科目別に月次集計表を自動生成（予算列との差分を自動着色）
- 毎月1日に前月データを取得して「月次サマリーシート」に追記
- 未払い・未収入金の件数・金額を自動集計してメール通知
- OAuth トークンのリフレッシュを自動化（毎月の再認証不要）

## 使用技術

- Google Apps Script
- freee API（会計 API v1）
- Google スプレッドシート
- Gmail API（月次通知）

## 工夫したポイント

- freee 側の勘定科目マスターを初回に取得してシートに保存し、API リクエスト数を最小化
- API エラー時は処理を止めてメールで通知（サイレント失敗を防ぐ）
- freee の操作が不要になるよう設計しつつ、確認したい場合は freee の該当ページへのリンクをシートに自動生成

## 効果

- 月次集計作業：3〜4時間 → 15分以内（確認・承認のみ）
- 予実比較レポートの完成：月末締め後2〜3日 → 翌日朝に自動生成
- freee へのログイン回数を週5〜6回 → ほぼゼロに削減

## 向いているクライアント

- freee を使っているが、スプレッドシートでの集計・分析も続けたい
- 月次の経理作業を圧縮して本業に集中したい（小規模事業者・フリーランス）
- freee API の設定は難しそうで触れていない
