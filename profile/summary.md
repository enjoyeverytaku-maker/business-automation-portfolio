# プロフィールサマリー

## 一言で言うと

**「スプレッドシートの手作業をなくす」専門家**。GAS × Python で経理・管理業務の自動化を担当。

---

## 強み

### 1. 業務理解から始める
コードを書く前にヒアリングで「なぜその作業をしているのか」を把握する。  
→ 「言われた通り」ではなく「本当に解決する」ものを作る。

### 2. 引き継げる状態で納品する
セットアップ手順・操作マニュアル・トラブルシューティングを必ず同梱。  
→ 担当者が変わっても自走できる。

### 3. 小さく始めてリスクを下げる
MVP（最小機能）を先に実装して動作確認→フルバージョンへ拡張。  
→ 「作ったけど使われない」を防ぐ。

## スキルセット

| スキル | レベル | 主な用途 |
|--------|--------|---------|
| Google Apps Script | ★★★★☆ | スプレッドシート自動化・メール通知・トリガー管理 |
| Python | ★★★☆☆ | CSV 整形・データクリーニング・スクレイピング |
| Google Workspace API | ★★★☆☆ | Docs/Drive/Gmail の操作自動化 |
| Notion API | ★★★☆☆ | DB 設計・データ同期 |
| Slack Webhook | ★★☆☆☆ | 通知連携 |

---

## 対応領域

- **経理・財務**: 請求書管理、入金照合、勘定科目整理
- **不動産業務**: 物件進捗管理、更新リマインド、書類チェックリスト
- **総務・管理**: 集計・報告自動化、締切リマインド、フォーム整形
- **GAS 全般**: トリガー設計、API 連携、シート設計

---

## 対応できないこと

- 常駐・出社が必要な業務
- Windows 専用・Office VBA のみの案件
- 週30時間以上のフルコミット案件
