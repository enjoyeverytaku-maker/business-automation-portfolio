# 対応ドメイン詳細

## 1. 経理・財務 × 自動化

### 得意な課題
- 毎月同じ手順で手入力している集計作業
- スプレッドシートへの転記・コピペ作業
- 請求書の金額チェック・突合作業
- CSV を会計ソフト向けに変換する作業

### 対応ツール
- freee API / CSVエクスポート連携
- マネーフォワード CSVエクスポート連携
- Google スプレッドシート + GAS

### 実装例
- 請求データをシートに貼り付けると自動で集計・分類
- 入金データと請求データを自動照合（消込補助）
- 月次締め処理の自動化（メール通知付き）

---

## 2. 業務自動化（GAS / スプレッドシート）

### 得意な課題
- 「毎週同じ操作をしている」「コピペが多い」作業
- スプレッドシートに入力したら自動で何かが起きてほしい
- メールや Slack で自動通知がほしい

### 対応ツール
- Google Apps Script
- Google スプレッドシート
- Gmail / Google Forms / Google Drive

### 実装例
- フォーム回答を自動でスプレッドシートに整形・集計
- 締切前日にメールで自動リマインド送信
- スプレッドシートの変更を検知して Slack 通知

---

## 3. 不動産業務

### 得意な課題
- 物件情報の管理・更新が手動で煩雑
- 契約書類・進捗状況の一元管理
- 売買・賃貸の管理表を毎月手で更新している

### 対応ツール
- Google スプレッドシート + GAS
- Notion（データベース活用）

### 実装例
- 物件ステータス管理表の自動集計・更新
- 契約進捗の可視化ダッシュボード
- 更新期限のリマインド自動化

---

## 4. Python データ処理

### 得意な課題
- 異なるフォーマットの CSV を統一フォーマットに変換
- 大量データのクレンジング・重複除去
- 会計ソフトへのインポート用データ加工

### 実装例
- 複数店舗の売上 CSV を統合・集計
- 住所・電話番号のフォーマット統一
- 勘定科目の自動分類（ルールベース）
