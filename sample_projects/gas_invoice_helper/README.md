# GAS 請求書・入金管理補助ツール

Google スプレッドシート + Google Apps Script で動く、小規模事業者向けの請求書・入金管理ツール。

## 機能

| 機能 | 説明 |
|------|------|
| 請求書番号自動採番 | `INV-YYYYMM-001` 形式で連番管理 |
| 請求書登録 | 税抜金額から消費税・合計を自動計算 |
| 入金ステータス更新 | 入金確認後にワンコールで更新 |
| 未入金リマインド | 支払期日 N 日前にメール自動送知 |
| 月次サマリー | 当月の請求・入金状況をログ出力 |

## セットアップ

### 1. スプレッドシートを準備

新規スプレッドシートを作成し、以下の2シートを追加する。

**請求書データ（ヘッダー行）**

```
A: 請求書番号 | B: 請求日 | C: 取引先ID | D: 取引先名
E: 金額(税抜) | F: 消費税 | G: 合計     | H: 支払期日
I: ステータス | J: 入金日 | K: 備考
```

**取引先マスター（ヘッダー行）**

```
A: 取引先ID | B: 取引先名 | C: 担当者名 | D: メールアドレス
```

### 2. スクリプトをコピー

Google Apps Script エディタを開き、以下の順でファイルを作成してコードをコピーする。

1. `config.gs` — 設定値
2. `utils.gs` — 共通ユーティリティ
3. `Code.gs` — メイン処理

### 3. `config.gs` を編集

```javascript
SPREADSHEET_ID: 'YOUR_SPREADSHEET_ID_HERE',  // スプレッドシートの ID に変更
NOTIFY_TO: 'accounting@example.com',          // 通知先メールに変更
```

スプレッドシート ID は URL の `/d/` と `/edit` の間の文字列。

### 4. トリガーをインストール

GAS エディタから `installTriggers` を手動実行する（1回だけ）。  
これで毎朝9時に自動リマインドチェックが走る。

## 使い方

### 請求書を登録する

```javascript
addInvoice({
  clientId:   'CLI-001',
  clientName: '株式会社サンプル',
  amount:     100000,    // 税抜金額
  dueDate:    '2026-05-31',
  note:       '4月分 業務委託費',
});
// → "INV-202604-001" が返る
```

### 入金を記録する

```javascript
markAsPaid('INV-202604-001');          // 今日付で入金済みに更新
markAsPaid('INV-202604-001', '2026-05-30');  // 日付を指定する場合
```

### 月次サマリーを確認する

```javascript
generateMonthlySummary();
// → 処理ログシートに当月の集計が出力される
```

## 設定一覧

`config.gs` で変更できる設定値：

| キー | デフォルト | 説明 |
|------|-----------|------|
| `TAX_RATE` | `0.10` | 消費税率 |
| `INVOICE_PREFIX` | `'INV-'` | 請求書番号のプレフィックス |
| `REMINDER_DAYS_BEFORE` | `7` | リマインドを送る日数（期日の何日前） |
| `NOTIFY_TO` | `'accounting@example.com'` | 通知先メールアドレス |
| `DRY_RUN` | `false` | `true` にするとメール送信をスキップ |

## ファイル構成

```
src/
  config.gs   設定値の管理
  utils.gs    共通ユーティリティ（ログ・日付・通貨フォーマット）
  Code.gs     メイン処理（採番・登録・更新・リマインド）
sample_data/
  clients.csv   取引先マスターのサンプルデータ
  invoices.csv  請求書データのサンプルデータ
```
