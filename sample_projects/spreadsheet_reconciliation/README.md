# GAS スプレッドシート照合ツール

銀行明細と帳簿データを自動で突き合わせ、照合結果を色分け出力する Google Apps Script ツール。

## 機能

| 機能 | 説明 |
|------|------|
| 自動照合 | 銀行明細と帳簿を金額・日付で突き合わせ |
| 日付ズレ吸収 | 着金遅延を `DATE_TOLERANCE_DAYS` で許容 |
| 結果出力 | 照合済／要確認／未照合を専用シートに一覧出力 |
| 色分けハイライト | 銀行明細の行をステータス別に色分け |

## ステータス定義

| ステータス | 説明 | 色 |
|-----------|------|-----|
| 照合済 | 金額・日付が完全一致 | 薄緑 |
| 要確認（日付ズレ） | 金額は一致、日付が1〜3日ズレ | 薄黄 |
| 未照合 | 対応する帳簿データなし | 薄オレンジ |

## セットアップ

1. スプレッドシートに「銀行明細」「帳簿データ」シートを作成
2. `src/config.gs` と `src/Code.gs` を GAS エディタにコピー
3. `SPREADSHEET_ID` を自分のシート ID に変更
4. `runReconciliation()` を手動実行

## シート構造

**銀行明細**
```
A: 取引日 | B: 摘要 | C: 入金額 | D: 出金額 | E: 残高
```

**帳簿データ**
```
A: 計上日 | B: 取引先名 | C: 金額 | D: 種別(入金/出金) | E: 請求書番号 | F: 備考
```

## 設定

`config.gs` で変更できる主な設定：

| キー | デフォルト | 説明 |
|------|-----------|------|
| `AMOUNT_TOLERANCE` | `0` | 金額の許容誤差（円） |
| `DATE_TOLERANCE_DAYS` | `3` | 日付の許容ズレ日数 |
| `DRY_RUN` | `false` | `true` で色付けをスキップ |

## ファイル構成

```
src/
  config.gs     設定値
  Code.gs       照合ロジック・出力
sample_data/
  bank_statement.csv  銀行明細サンプル
  ledger.csv          帳簿データサンプル
```
