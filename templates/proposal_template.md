# 提案文テンプレート

クラウドソーシングへの応募文の雛形です。案件に合わせて編集してください。

---

## 提案文

```
はじめまして。[スキル・強み1〜2文で端的に]。

---

【ご要望の理解】
[案件で依頼されている内容を自分の言葉で1〜2文にまとめる]

【進め方（プロセス保証）】
以下のステップで進めることを想定しています。

① ヒアリング（〜1営業日）
　現在の運用フロー・ファイル構成・ゴールを確認します。
　不明点は事前に質問票（Markdown形式）でお送りします。

② 仕様確定（〜1営業日）
　ヒアリングを元に「仕様書」を作成し、着手前にご確認いただきます。
　認識齟齬はこの時点で解消します。

③ 開発・テスト（〜X営業日）
　[使用技術] を使って実装。テスト用サンプルデータで動作確認後に納品します。

④ 納品・サポート（〜3日）
　セットアップ手順書・操作マニュアルを同梱します。
　納品後3日以内の修正対応は無償で対応します。

【確認させてください】
- [質問1]
- [質問2]

ご不明点・ご要望があればお気軽にご連絡ください。よろしくお願いいたします。
```

---

## 短い初回返信

```
はじめまして。[スキル・実績を1文で]。
[案件内容を理解した上で、進められると思う旨を端的に]。
まず [質問1] を確認させていただけますでしょうか？
```

---

## 事前確認チェック

- [ ] 案件の要件を1文で言えるか
- [ ] no_go 条件（常駐・出社・週30h以上）が含まれていないか
- [ ] 提案文中に断定表現がないか（「できます」→「対応可能と考えています」）
- [ ] CTAが入っているか（質問・次の一手）
