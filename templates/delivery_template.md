## 納品前チェック

### コード品質
- [ ] 動作確認済み（正常系・異常系）
- [ ] 機密情報（API キー等）がコードに含まれていない
- [ ] `YOUR_XX_HERE` などのプレースホルダーが設定例に変換済み

### ドキュメント
- [ ] README に必要な情報がすべて記載されている
- [ ] セットアップ手順を初見の人が実行できる粒度で記述している
- [ ] 操作マニュアルにスクリーンショットまたはコマンド例がある

### テスト
- [ ] 受入確認チェックリストを埋めた
- [ ] エラーハンドリングの動作を確認した
